Installing

Quick answers

Windows shows a warning — is that normal?

Yes. The installer is not signed yet, so Windows warns about it. In the blue dialog click “More info” → “Run anyway”.

Windows 11 will not let the program run at all

Smart App Control is on. To turn it off: Windows Security → App & browser control → Smart App Control settings → Off. It can only be turned back on by reinstalling Windows, so decide for yourself — or use the Android version.

How do I update?

Download the new version and install it over the old one — your identity and chats are kept. One exception: Android build 30 or older has to be uninstalled once, and your identity and chats on that device go with it.

How do I start my first chat?

Tap “Create my identity” — no sign-up. Then one of you opens “New chat” → “Invite” and shows the QR or the short code, and the other chooses “Join”. Share the code only with the person you want to talk to.
