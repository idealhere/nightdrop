Скачать для Android

Скачать для Windows
  1. Нажмите «Скачать для Windows».
  2. Браузер может предупредить, что файл скачивают редко, — выберите «Сохранить». В Microsoft Edge эта кнопка спрятана: стрелка рядом с «Удалить» → «Сохранить всё равно».
  3. Запустите файл. В синем окне Windows нажмите «Подробнее», затем «Выполнить в любом случае».
  4. Пройдите установщик — права администратора не нужны. Приложение появится в меню «Пуск».

Установщик пока не подписан, поэтому Windows показывает предупреждения. Если включено «Интеллектуальное управление приложениями» (Smart App Control), Windows 11 не даст запустить программу. Выключить его можно так: Безопасность Windows → Управление приложениями и браузером → Параметры интеллектуального управления приложениями → Выкл. Включить обратно получится только переустановкой Windows, поэтому решайте сами — либо пользуйтесь версией для Android.

Как начать переписку

  1. 01Нажмите «Создать мою личность». Ни регистрации, ни телефона, ни почты.
  2. 02Один из вас открывает «Новый чат» → «Пригласить»: появится QR и короткий код.
  3. 03Второй открывает «Новый чат» → «Присоединиться» и сканирует QR или вводит код.
  4. 04Чат устанавливается сам. Можно писать и отправлять фото и видео.
  5. 05Откройте «Проверить код безопасности», сверьте цифры и отметьте чат проверенным.

Передавайте код приглашения только тому, с кем хотите общаться, и по каналу, которому доверяете: тот, кто введёт код, сразу попадёт в чат.
